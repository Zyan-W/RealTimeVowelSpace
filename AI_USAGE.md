# AI Usage

This project has been developed and reviewed with assistance from OpenAI Codex.

AI assistance was used for implementation, refactoring, documentation, dependency/license review, and test verification. The project policy is:

- Do not ask AI tools to copy code from specific open-source repositories, blogs, Stack Overflow answers, or papers.
- Use public API documentation and general programming or mathematical ideas only.
- Keep generated implementation code short, conventional, and project-specific.
- Review dependency licenses before adding new packages.
- Prefer permissive dependencies such as Apache-2.0, MIT, BSD, or ISC.
- Avoid GPL, AGPL, SSPL, BUSL, and unclear-license dependencies unless the project owner explicitly approves them.

Current AI-assisted code in this repository is intended to be original project code licensed under Apache-2.0. AI output should still be reviewed by a human maintainer before release.
